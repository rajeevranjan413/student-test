# Home page images

Drop real photos here and the public landing page (`/`) picks them up
automatically. Until a file exists, each slot shows a branded gradient, so the
page always looks finished.

| File            | Where it shows          | Suggested size |
|-----------------|-------------------------|----------------|
| `hero.jpg`      | Hero showcase (top right)| ~1200×900, landscape |
| `classroom.jpg` | Gallery — large tile    | ~1200×900 |
| `banner.jpg`    | Gallery — top-right tile| ~800×600 |
| `toppers.jpg`   | Gallery — bottom-right  | ~800×600 |

Use JPG or WebP, optimized for web. Filenames must match exactly (lowercase).
